# Togalu Gombe

## Reviving Karnataka’s Traditional Shadow Puppetry Through Technology

Togalu Gombe is an Android application inspired by **Togalu Gombeyaata**, the ancient leather shadow puppetry art of Karnataka. The project is designed to preserve and modernize this traditional storytelling form by making it more engaging, interactive, and understandable for younger generations through digital technology.
The application acts as a **Digital Shadow-Theater Companion**, helping audiences follow live performances using simplified scene summaries, character explanations, multimedia content, and interactive puppet galleries. By blending culture with technology, Togalu Gombe aims to bridge the gap between traditional folk arts and modern digital audiences.

# Problem Statement

Togalu Gombeyaata is one of Karnataka’s oldest and most culturally significant visual storytelling traditions. Through handcrafted leather puppets, artists narrate mythological epics such as the *Ramayana* and *Mahabharata*. Despite its rich heritage, the art form is gradually losing popularity among younger generations.
One of the major challenges is the use of **Old Kannada** during performances, which many modern viewers find difficult to understand. While the performances are visually beautiful, audiences often struggle to follow the storyline, dialogues, and symbolism behind the characters.
In addition, today’s younger generation is more accustomed to fast-paced digital content and interactive entertainment. Traditional puppet performances may appear slow or difficult to engage with when compared to modern media platforms. As a result, interest in folk arts is steadily decreasing.
Another issue is the lack of digital accessibility and awareness about the craftsmanship involved in Togalu Gombeyaata. Many people are unaware of the intricate leather art, puppet-making techniques, and the cultural significance behind the performances.

Togalu Gombe addresses these problems by providing a modern digital platform that:

* Simplifies stories into easy-to-understand summaries
* Offers multilingual accessibility
* Creates interactive learning experiences
* Promotes traditional artists and handicrafts
* Preserves cultural storytelling for future generations

# Features:
## Live Assist
* Scene-by-scene summaries for live performances
* Simple Kannada and English explanations
* Swipe navigation between scenes
* Helps audiences follow stories in real time

## Interactive Puppet Gallery
* Explore detailed leather puppet collections
* Zoomable images to observe intricate perforation artwork
* Character descriptions and mythological symbolism

## Puppet Scan (Simulated)
* Simulated scanning experience for identifying puppets
* Displays character name, powers, and role in the story

## Artist Connect
* Information about puppet-making workshops
* Support local artisans by promoting miniature puppets and handicrafts

## History Feed
* Educational content about:
  * Leather curing techniques
  * Puppet coloring methods
  * Traditional crafting processes

## Dark-Themed UI
* Designed to replicate the atmosphere of traditional shadow theater performances

## Multimedia Support
* Traditional music and cultural audio playback integration

## Multilingual Support
* Kannada language support
* English translations for broader accessibility

# Setup Instructions
## Prerequisites
Before running the project, make sure you have:
* Android Studio installed
* Android SDK configured
* Kotlin support enabled
* Git installed
* Internet connection for Gradle dependencies

# Clone the Repository

```bash
git clone https://github.com/yourusername/togalu-gombe.git
```

# Open the Project
1. Open Android Studio
2. Click on **Open**
3. Select the cloned project folder
4. Wait for Gradle Sync to complete

# Run the Application

## Using Android Emulator
1. Open **Device Manager**
2. Create or start an Android Virtual Device (AVD)
3. Click the **Run ▶** button

## Using Physical Device
1. Enable "Developer Options"
2. Enable "USB Debugging"
3. Connect the device via USB
4. Click "Run ▶" in Android Studio


# Build APK

To generate the APK file:

```text
Build → Build Bundle(s) / APK(s) → Build APK(s)
```

Generated APK location:

```text
app/build/outputs/apk/debug/
```
